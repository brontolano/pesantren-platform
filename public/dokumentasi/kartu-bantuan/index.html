Kartu Bantuan Cepat

Contekan satu halaman per peran — siap cetak, laminating, dan tempel di meja kerja.

Cara pakai: cetak halaman peran yang sesuai, laminating/masukkan plastik, tempel di meja kerja. Satu kartu = satu halaman A4 (atau A5 bolak-balik). Huruf besar supaya terbaca tanpa kacamata. 😊

✂️ KARTU 1 — SEMUA STAF (sisi depan)#

╔══════════════════════════════════════════════════╗
║      MASUK KE APLIKASI PESANTREN                  ║
║                                                    ║
║  1. Buka CHROME                                    ║
║  2. Ketik:  _________________________ /admin       ║
║     (tulis alamat pesantren Anda di garis itu)     ║
║  3. Isi EMAIL + KATA SANDI → tombol MASUK          ║
║                                                    ║
║  Lupa kata sandi?  → WA admin: ______________      ║
║                                                    ║
║  ───────────────────────────────────────────       ║
║  ADA ERROR / LAYAR ANEH?                           ║
║  1. JANGAN PANIK — data tidak rusak                ║
║  2. Foto layar (Power + Vol.Bawah)                 ║
║  3. Kirim WA ke admin + ceritakan singkat          ║
║  ───────────────────────────────────────────       ║
║  ATURAN EMAS:                                      ║
║  • Selesai isi formulir → klik SIMPAN              ║
║  • JANGAN klik HAPUS tanpa izin atasan             ║
║  • Pulang kerja di komputer bersama → KELUAR       ║
╚══════════════════════════════════════════════════╝

✂️ KARTU 2 — TATA USAHA#

╔══════════════════════════════════════════════════╗
║  TATA USAHA — PETA MENU                            ║
║                                                    ║
║  Tambah santri baru                                ║
║   → Kesantrian → Santri → + Tambah                 ║
║     (NIS tidak boleh kembar!)                      ║
║                                                    ║
║  Naik kelas / pindah kelas                         ║
║   → Kesantrian → Penempatan Kelas → + Tambah       ║
║     (yang lama otomatis jadi riwayat)              ║
║                                                    ║
║  Santri lulus / keluar / cuti                      ║
║   → Kesantrian → Santri → Edit → ubah STATUS       ║
║     ⛔ BUKAN dihapus!                              ║
║                                                    ║
║  Cetak daftar santri                               ║
║   → Kesantrian → Santri → Filter → Export/Cetak    ║
║                                                    ║
║  Pendaftar baru (PPDB)                             ║
║   → PPDB → Calon Santri                            ║
║   Terima/tolak → Edit → Status                     ║
║   Resmikan → tombol REGISTRASI ULANG               ║
╚══════════════════════════════════════════════════╝

✂️ KARTU 3 — BENDAHARA#

╔══════════════════════════════════════════════════╗
║  BENDAHARA — PETA MENU                             ║
║                                                    ║
║  Tagihan 1 santri                                  ║
║   → Keuangan → Tagihan → + Tambah                  ║
║  Tagihan 1 kelas sekaligus                         ║
║   → Keuangan → Tagihan → + Tambah → PER KELAS      ║
║     (nominal TANPA titik: 150000)                  ║
║                                                    ║
║  Terima uang / bukti transfer                      ║
║   → Keuangan → Pembayaran → + Tambah               ║
║   lalu klik VERIFIKASI ✅ (setiap hari!)           ║
║                                                    ║
║  Siapa belum bayar?                                ║
║   → Keuangan → Tagihan → Filter → Status: belum    ║
║                                                    ║
║  Tabungan santri (setor/tarik)                     ║
║   → Keuangan → Tabungan Santri                     ║
║  Wali isi saldo dari HP? CEK & SAHKAN:             ║
║   → Keuangan → Verifikasi Topup                    ║
║                                                    ║
║  Rekap bulanan → Keuangan → Laporan Keuangan       ║
║  Buku kas resmi → Buku Besar → Buku Kas Umum       ║
║                                                    ║
║  ⛔ JANGAN HAPUS catatan uang. Salah? Lapor admin. ║
╚══════════════════════════════════════════════════╝

✂️ KARTU 4 — GURU / USTADZ#

╔══════════════════════════════════════════════════╗
║  GURU — PETA MENU                                  ║
║                                                    ║
║  Masukkan nilai (0–100)                            ║
║   → Akademik → Input Nilai → + Tambah              ║
║     (nilai lengkap = rapor jadi otomatis)          ║
║                                                    ║
║  Lihat rapor                                       ║
║   → Akademik → Rapor                               ║
║                                                    ║
║  Setoran hafalan                                   ║
║   → Tahfidz → Hafalan Tahfidz → + Tambah           ║
║  Nilai hafalan                                     ║
║   → Tahfidz → Penilaian Tahfidz → + Tambah         ║
║                                                    ║
║  Izin santri (setujui/tolak)                       ║
║   → Kegiatan & Perizinan → Izin Santri             ║
║                                                    ║
║  Catat kegiatan/acara                              ║
║   → Kegiatan & Perizinan → Kegiatan → + Tambah     ║
╚══════════════════════════════════════════════════╝

✂️ KARTU 5 — PENGURUS WEBSITE / HUMAS#

╔══════════════════════════════════════════════════╗
║  WEBSITE — PETA MENU                               ║
║                                                    ║
║  Tulis berita                                      ║
║   → Website & CMS → Artikel → + Tambah             ║
║     (teliti nama & gelar sebelum terbit!)          ║
║                                                    ║
║  Album foto kegiatan                               ║
║   → Website & CMS → Galeri → + Tambah              ║
║     (10–20 foto terbaik saja)                      ║
║                                                    ║
║  Ganti profil / sambutan                           ║
║   → Website & CMS → Profil Website                 ║
║  Ganti logo / alamat / telepon                     ║
║   → Website & CMS → Identitas & Kontak             ║
║                                                    ║
║  Simpan brosur / dokumen                           ║
║   → File Storage → File Media → + Tambah           ║
║                                                    ║
║  CEK HASIL: buka alamat website TANPA /admin       ║
║  🔒 Jangan unggah KK/akta/data pribadi ke publik   ║
╚══════════════════════════════════════════════════╝

💡 Tips cetak: buka file ini → Ctrl+P → atur 1 kartu per halaman → cetak → potong sesuai garis ✂️. Isi dulu garis kosong (alamat aplikasi & nomor WA admin) dengan spidol sebelum laminating.
