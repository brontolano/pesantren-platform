Pengurus Website

Menulis berita, unggah galeri foto, profil & kontak pesantren, dan penyimpanan file.

Syarat: sudah menyelesaikan 🌱 Panduan Dasar. Setiap pesantren punya website umum (bisa dilihat siapa saja di internet, tanpa kata sandi). Isi website itu — berita, foto, profil — Bapak/Ibu yang mengatur dari panel admin. Begitu disimpan, tampilan website langsung berubah. Tidak perlu jasa pembuat website lagi.

Daftar isi:

  1. Melihat website pesantren
  2. Menulis & menerbitkan berita (artikel)
  3. Mengunggah album foto (galeri)
  4. Mengubah profil & kontak pesantren
  5. Mengelola file (brosur, formulir, dokumen)
  6. Pengingat penting

1. Melihat Website Pesantren#

Buka alamat website pesantren di Chrome tanpa /admin, contoh: https://albakids.pesantren.online

Itulah yang dilihat masyarakat: profil, berita, galeri, info pendaftaran (PPDB), jadwal sholat. Setelah Bapak/Ibu mengubah sesuatu di panel admin, buka lagi alamat ini untuk memeriksa hasilnya.

💡 Kebiasaan baik: selesai mengubah apa pun → selalu cek tampilannya di website asli.

2. Menulis & Menerbitkan Berita (Artikel)#

Kapan dipakai: ada kegiatan, pengumuman, prestasi santri, info PPDB.

Siapkan dulu: judul, isi tulisan (boleh diketik dulu di WA/catatan HP), 1 foto utama.

Langkahnya:

  1. Menu kiri → Website & CMS → Artikel.
  2. Ketuk + Tambah.
  3. Isi:
    • Judul — singkat dan jelas. Contoh: Santri Asy-Syifaa Juara 1 MTQ Kabupaten.
    • Isi tulisan — ketik di kotak besar. Ada tombol-tombol seperti di Word (huruf tebal B, miring I, daftar).
    • Foto utama — ketuk tombol unggah → pilih foto dari HP/komputer.
    • Kategori — pilih bila ada (berita / pengumuman / dll.).
  4. Pilih terbitkan (publish) bila ingin langsung tampil, atau simpan sebagai konsep (draft) bila belum selesai.
  5. Ketuk Simpan.
✅ **Tanda berhasil:** buka website pesantren (Bagian 1) → berita baru muncul di halaman berita.

⚠️ Kalau ada masalah:

  • Foto tidak mau terunggah → ukuran foto terlalu besar. Foto dari kamera HP bisa 5–10 MB. Kecilkan dulu (kirim ke diri sendiri via WA, lalu pakai foto hasil unduhan WA — otomatis lebih kecil).
  • Sudah terbit tapi ada salah ketik → tidak masalah. Edit → betulkan → Simpan. Website langsung terbarui.

3. Mengunggah Album Foto (Galeri)#

Kapan dipakai: dokumentasi kegiatan — wisuda tahfidz, lomba, pembangunan.

Langkahnya:

  1. Menu kiri → Website & CMS → Galeri.
  2. Ketuk + Tambah.
  3. Isi judul album. Contoh: Wisuda Tahfidz 2026.
  4. Isi keterangan singkat.
  5. Ketuk tombol unggah foto → pilih beberapa foto sekaligus (di HP: ketuk lama foto pertama, lalu ketuk foto lainnya).
  6. Tunggu sampai semua foto selesai terunggah (jangan menutup halaman saat masih berputar).
  7. Ketuk Simpan.

✅ Tanda berhasil: album muncul di halaman Galeri website.

⚠️ Pilih foto yang pantas: wajah santri jelas itu boleh selama wali tidak keberatan, tapi hindari foto yang memperlihatkan aurat, lokasi kamar, atau data pribadi (KK/akta). Kalau ragu, tanya pimpinan dulu. Yang sudah tayang di internet sulit ditarik kembali.

4. Mengubah Profil & Kontak Pesantren#

Kapan dipakai: ganti nomor telepon, alamat, sambutan kyai, sejarah, visi-misi, atau logo.

Langkahnya:

  1. Menu kiri → Website & CMS → Profil Website (untuk isi profil) atau Identitas & Kontak (untuk nama, logo, alamat, telepon).
  2. Ubah bagian yang perlu. Yang lain biarkan.
  3. Ketuk Simpan.
  4. Buka website asli → periksa perubahan sudah tampil.

✅ Tanda berhasil: website menampilkan info baru.

💡 Pengaturan tampilan lain (warna, susunan halaman) ada di Website & CMS → Pengaturan Website dan Website Builder. Kalau belum yakin, jangan ubah-ubah bagian ini tanpa didampingi admin — tidak berbahaya, tapi bisa membuat tampilan jadi tidak rapi.

5. Mengelola File (Brosur, Formulir, Dokumen)#

Kapan dipakai: menyimpan brosur PPDB, formulir, surat edaran — supaya bisa dibagikan lewat tautan (link).

Langkahnya:

  1. Menu kiri → File Storage → File Media.
  2. Ketuk + Tambah.
  3. Beri nama yang jelas. Contoh: Brosur PPDB 2026-2027.
  4. Ketuk tombol unggah → pilih file (PDF, gambar, Excel).
  5. Simpan.

✅ Tanda berhasil: file muncul di daftar, lengkap dengan tautan yang bisa disalin dan dibagikan via WA.

💡 Setiap unggahan tercatat di File Storage → Riwayat Media (siapa mengunggah apa, kapan) — jadi aman dan bisa dilacak.

6. Pengingat Penting#

  1. ✍️ Teliti sebelum terbit. Baca dua kali: nama orang, gelar kyai, tanggal acara. Salah tulis di internet dilihat banyak orang.
  2. 🖼️ Foto secukupnya per album (10–20 foto terbaik), bukan semua isi memori HP — supaya website tetap cepat dibuka dan kuota penyimpanan tidak cepat habis.
  3. 🔒 Jangan unggah dokumen berisi data pribadi (KK, akta, ijazah santri) ke galeri/artikel yang bisa dilihat umum.
  4. 📅 Website yang hidup = berita rutin. Targetkan minimal 1 berita per minggu — ini juga membuat pesantren mudah ditemukan di Google.
  5. 📸 Ada masalah? Foto layar → kirim admin.

Contekan Cepat Pengurus Website#

Mau apa? Buka di mana?
Tulis berita Website & CMS → Artikel → + Tambah
Perbaiki berita terbit Website & CMS → Artikel → Edit
Unggah album foto Website & CMS → Galeri → + Tambah
Ganti profil/sejarah Website & CMS → Profil Website
Ganti logo/alamat/telepon Website & CMS → Identitas & Kontak
Simpan brosur/dokumen File Storage → File Media
