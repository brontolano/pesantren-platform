# Kesehatan — Peta Modul (AGENTS.md)
> Orientasi cepat. Untuk tugas di modul ini, muat: folder Modules/Kesehatan/ + .d.ts terkait + resources/js/Components/Ui/README.md. Acuan: docs/KONVENSI.md, docs/PLAYBOOK-IRISAN.md.

**Domain:** Riwayat kesehatan santri, kunjungan UKS, stok & mutasi obat, sesi konseling. Non-uang (rujukan_biaya hanya dicatat, tidak diposting ke Ledger).
**Model inti:** (di Modules/Kesehatan/app/Models/) RiwayatKesehatan (tabel `riwayat_kesehatan`), KunjunganUks (`kunjungan_uks`, WP-27, status pulang|istirahat|rujuk), Obat (`obat`, WP-28, scope menipis, tanpa batch/expiry), ObatMutasi (`obat_mutasi`, append-only, jenis masuk|keluar, morph ref), SesiKonseling (`sesi_konseling`).
**Service/Event inti:** KesehatanService (catatKesehatan/jadwalkanKonseling/catatKunjungan/getDaftarIstirahat/getDaftarRujukanTerbuka), ObatService (masuk/keluar via lockForUpdate, stok tak boleh minus), KunjunganUksObserver (didaftarkan di Providers/EventServiceProvider) — auto-sync PresensiSantri (status istirahat → presensi 'sakit', selain itu hapus).
**UI Filament:** SEKARANG di app/Filament/Resources/Kesehatan/ → ObatResource, RiwayatKesehatanResource, SesiKonselingResource (+ Pages List/Create/Edit masing-masing). navigationGroup='Kesantrian', semua moduleVisible('kesehatan') + can('view_santri'). Target pindah: Modules/Kesehatan/app/Filament/. Catatan: KunjunganUks BELUM punya Resource Filament (hanya via PWA Guru).
**Endpoint/portal terkait:** routes/api.php — apiResource v1/kesehatans + PWA Guru UKS (`pwa.guru.uks.*`: obat, istirahat, rujukan-terbuka, catat-kunjungan, {id}/tutup, {santri}/riwayat via PwaGuruUksController). routes/web.php — resource `kesehatan`. routes/tenant.php — `tenant.uks.*` (UksDemoController, showcase demo) + `portal-wali ... kesehatan` (PortalWaliKesehatanController).
**Migrasi & seeder:** Modules/Kesehatan/database/migrations/ — 2026_06_04 (riwayat_kesehatan, sesi_konseling), 2026_06_11 (kunjungan_uks), 2026_06_12 (obat, obat_mutasi). KesehatanDatabaseSeeder kosong (no-op).
**Jebakan modul ini:** (1) Stok obat HANYA lewat ObatService (lockForUpdate, transaksi) — JANGAN tulis Obat::stok langsung; setiap perubahan wajib jejak obat_mutasi. (2) Tenancy: semua model BelongsToTenant, DB-per-tenant fisik. (3) Filament v5 grup+item berikon → panel authed 500; WAJIB jalankan TenantPanelAuthedSmokeTest tiap ubah Resource. (4) catatKunjungan idempoten per (santri,tanggal) via updateOrCreate; observer menyentuh PresensiSantri (modul Akademik) — hati-hati efek samping presensi.
**Status rollout 5-lapisan:** Gelombang G3 (non-uang). Tidak menyentuh JurnalService/Ledger. Karena ada Resource Filament + gate moduleVisible/permission, perubahan UI butuh smoke authed (TenantPanelAuthedSmokeTest).
