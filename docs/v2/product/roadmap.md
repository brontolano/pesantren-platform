# Roadmap v2

1. Fondasi operator: autentikasi terpisah, organisasi draf, identitas/domain, audit.
2. Provisioning dapat dipulihkan: state setup, domain unik, retry idempoten, database tenant, admin pertama dan undangan lokal.
3. Tata kelola layanan: status layanan, katalog availability, hasil probe teknis terpisah, langkah pemulihan.
4. Kesiapan staging: MFA operator, isolasi database/session/storage, restore drill, audit keamanan dan uji aksesibilitas.
5. Tenant pilot: validasi istilah, alur setup, penggunaan mobile dan kebutuhan support dengan organisasi uji yang datanya disetujui.
6. Evaluasi metrik dan roadmap produk: ukur LCP/INP/CLS, p95, biaya runtime dan recovery pada staging sebelum memilih modul selanjutnya.

PPDB, kesantrian, keuangan, Portal Orang Tua, impersonasi, hapus permanen, migrasi data v1, dan peluncuran publik berada di luar fase fondasi ini.
